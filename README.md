# Dungeon Escape

Dungeon Escape is a first-person Unreal Engine 5 game project developed as part of the **Unreal Engine 5 C++ Game Development (Fully Updated in 5.7)** course by **GameDev.tv** on **Udemy**.  
The project focuses on learning core Unreal Engine concepts using C++, including player interaction, actor components, collision detection, trigger volumes, lighting setup, material usage, and puzzle-based gameplay mechanics.

Course Link:  
https://www.udemy.com/course/unrealcourse/

---

## Project Overview

Dungeon Escape is a puzzle-based dungeon escape game where the player must explore a medieval dungeon environment, interact with objects, and solve simple physics-based puzzles to progress.  
The project emphasizes hands-on C++ gameplay programming in Unreal Engine 5, while also introducing environment setup, lighting, and material workflows.

Key learning outcomes include:
- Unreal Engine 5 C++ fundamentals
- Actor and component-based architecture
- Player input and interaction systems
- Collision detection and trigger volumes
- Physics-based object manipulation
- Puzzle and level design implementation
- Lighting setup for dungeon environments
- Material setup and asset customization

## Assets & Resources Used

The following assets were used in this project:

Due to GitHub repository size limitations, the **Medieval Dungeon** asset is **NOT included** in this repository and **must be downloaded separately** before opening the project in Unreal Engine.

After downloading, import the asset into the Unreal Engine project using the **Content Drawer** or **Add Feature or Content Pack** options as appropriate.

## Lighting & Materials

This project includes a custom dungeon lighting setup designed to create a dark medieval atmosphere while keeping gameplay areas readable for the player.

Lighting and material work includes:
- Environment lighting setup for dungeon rooms and corridors
- Point lights and/or local light sources to highlight key gameplay areas
- Material assignment and adjustment for dungeon meshes
- Use of Starter Content materials where appropriate
- Asset and material setup to improve visual consistency across the level

## Getting Started

1. Clone the repository.
2. Open the project using **Unreal Engine 5.7**.
3. Download and import the required assets listed above.
4. Import or enable the **Unreal Engine 5.6 Starter Content** if it is missing.
5. Generate Visual Studio project files if prompted.
6. Build and run the project from the Unreal Editor.
